# 💬 Real-Time Chat App

A full-stack real-time chat application built with the MERN stack and Socket.io.

## 🚀 Live Demo
- **Frontend:** [Live on Vercel](https://nexsoft-chat-app.vercel.app/)
- **Backend:** Coming Soon
- **Demo Video:** Coming Soon

## ✨ Features
- 🔐 User Authentication (Register/Login)
- 💬 Real-Time Messaging with Socket.io
- 👥 Multiple Chat Rooms
- 🔒 JWT Token Security
- 📱 Fully Responsive Design

## 🛠️ Tech Stack

### Frontend
- React.js 19
- Vite
- Socket.io Client
- React Router DOM
- Lucide React (Icons)
- CSS / Tailwind

### Backend
- Node.js
- Express.js
- Socket.io
- MongoDB + Mongoose
- JWT Authentication
- bcryptjs

## ⚙️ Run Locally

### 1. Clone the repo
git clone https://github.com/YOUR_USERNAME/realtime-chat-app.git
cd realtime-chat-app

### 2. Install all dependencies
npm run install-all

### 3. Setup Backend .env
cd backend
create .env file:
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret_key
PORT=5000

### 4. Run the app
cd ..
npm run dev
